Put a FEW photos here (the site shows only a few, not the whole catalog):
  hero.jpg                  -> big image on home (optional)
  showcase/*.jpg            -> up to 12 featured bags on Home + Brands
  brands/<slug>.jpg         -> cover for a brand folder, e.g. brands/chanel.jpg, brands/bottega-veneta.jpg
  reviews/*.jpg             -> customer review screenshots (up to 12)
  delivered/*.jpg           -> FedEx delivery proofs (up to 12)
Tip: resize to ~1000px wide, save as .jpg/.webp (under 200 KB each). Then run: npm run build
